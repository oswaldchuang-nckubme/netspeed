# 網速計

手機可安裝的網速測試 PWA，部署於 GitHub Pages。

## 部署
1. 在 GitHub 建立新 repository（例如 `netspeed`），上傳本資料夾所有檔案（含 `.github` 資料夾）。
2. Settings → Pages → Source 選 **GitHub Actions**。
3. 推送到 `main` 後約 1 分鐘，網址為 `https://<帳號>.github.io/<repo名>/`。

## 安裝到手機
- Android（Chrome）：開啟網址 → 選單 → 安裝應用程式。
- iPhone（Safari）：開啟網址 → 分享 → 加入主畫面。
